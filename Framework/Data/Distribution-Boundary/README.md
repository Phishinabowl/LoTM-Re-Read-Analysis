# Distribution Boundary Fixtures

This directory contains adversarial data for the optional commercial distribution and entitlement
boundary. `adversarial-external-metadata.json` is intentionally **not** a supported offering,
entitlement, or provider schema. It models external claims that must remain inert when placed beside
portable framework and project configuration.

The paired `distribution-boundary` conformance suite proves that the fixture cannot satisfy pack
dependencies, change pack or capability lifecycle, select packs, activate capabilities, add
controlled values, or mutate project composition. It also simulates an unavailable entitlement
provider and proves that installed local state remains unchanged.
